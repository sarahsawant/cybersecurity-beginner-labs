# Windows Networking Commands – Practical Lab

## Aim
To understand basic networking commands in Windows and learn how to check network configuration, connectivity, DNS resolution, and network routes.

## Tools Used
- Windows Command Prompt
- Windows networking utilities

## Commands Performed

### 1. IP Configuration
**Command:** `ipconfig`

Displays the device's network configuration, including its IPv4 address, subnet mask, and default gateway.

### 2. Connectivity Test
**Command:** `ping google.com`

Checks whether my computer can communicate with Google's server and receive replies.

### 3. DNS Lookup
**Command:** `nslookup google.com`

Finds the IP address associated with a domain name using DNS.

### 4. Route Tracing
**Command:** `tracert google.com`

Shows the network path taken by data packets to reach a destination.

## Observation
I successfully ran all four networking commands using Windows Command Prompt. I also learned how each command helps troubleshoot basic network issues.

On my system, I had to use the full executable paths from `C:\Windows\System32` because the commands were not initially recognised by Command Prompt.

This practical helped me understand how to:
- Check my computer's network configuration.
- Test internet connectivity.
- Understand how DNS translates domain names into IP addresses.
- Trace the route taken by network traffic.

This was a beginner-level hands-on exercise in networking fundamentals.
