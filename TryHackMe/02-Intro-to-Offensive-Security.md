# TryHackMe – Intro to Offensive Security

**Platform:** TryHackMe  
**Category:** Offensive Security  
**Level:** Beginner  
**Status:** Completed

## 1. Objective

To understand the fundamentals of offensive security and how ethical hackers identify vulnerabilities in computer systems and web applications.

## 2. Concepts Learned

- Introduction to offensive security
- Ethical hacking and penetration testing
- Identifying vulnerabilities
- Web application security
- Discovering hidden website directories
- Understanding how attackers exploit security weaknesses

## 3. Tools Explored

- Gobuster – A directory and file discovery tool used to identify hidden resources on websites.

## 4. Practical Learning

Worked through TryHackMe's simulated FakeBank environment to understand how security weaknesses can be discovered through authorised testing.

## 5. Key Takeaways

- Offensive security helps identify vulnerabilities before malicious attackers exploit them.
- Ethical hacking must always be performed with proper authorisation.
- Tools such as Gobuster help security professionals discover potentially exposed website resources.

## 6. Skills Developed

- Basic vulnerability identification
- Understanding web application security
- Introduction to ethical hacking
- Familiarity with directory enumeration
