WIRESHARK LAB 03 – TCP THREE-WAY HANDSHAKE

Date: 15 November 2026

AIM:
To capture TCP packets and understand how a connection is established using the three-way handshake.

TOOL USED:
Wireshark

FILTERS USED:

1. Initial SYN:
tcp.flags.syn == 1 && tcp.flags.ack == 0

2. SYN-ACK:
tcp.flags.syn == 1 && tcp.flags.ack == 1

3. Final ACK:
tcp.flags.syn == 0 && tcp.flags.ack == 1

OBSERVATIONS:

1. SYN – The client sends a connection request to the server.
2. SYN-ACK – The server acknowledges the request and responds.
3. ACK – The client acknowledges the server's response.

Connection Details:
- Client IP: 192.168.0.103
- Client port: 56982
- Server port: 443
- Protocol: TCP
- Service: HTTPS

LEARNING OUTCOME:

Learned how TCP establishes connections through a three-way handshake and how to identify SYN, SYN-ACK and ACK flags using Wireshark filters.
