# WIRESHARK LAB 01 – NETWORK PACKET ANALYSIS

**Aim:** To capture and analyze network packets using Wireshark.

**Software Used:** Wireshark, Npcap

### 1. Theory
Wireshark is an open-source network protocol analyzer used to capture and examine network traffic.

### 2. Procedure
1. Opened Wireshark.
2. Selected the Wi-Fi interface.
3. Started packet capturing.
4. Applied DNS, TCP, UDP and ICMP filters.
5. Examined packet details.

### 3. Observations

| Protocol | Purpose |
|---|---|
| DNS | Domain name resolution |
| TCP | Reliable data transmission |
| UDP | Connectionless communication |
| ICMP | Network diagnostics |

### 4. Result
Successfully captured and analyzed network packets using Wireshark.

### 5. Conclusion
Learned how to capture network traffic and identify different network protocols using Wireshark.
